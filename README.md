### About

This is a bugtracker application where there are 3 roles Developer, User and Tester. Basically this sites allows user to create a bug if they find to any website. developer can login and see if there are any bug on his added project in order to create a bug user has to select a project. Hence developer can look into the bug and resolve it or deprecate it as per needs. Later users can see the status of the reported bug about what developer says on it or if its deprecated and why.
